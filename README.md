# Simulador PAUT de soldas

Simulador no navegador de inspeção por ultrassom phased array (PAUT) em juntas soldadas, para treino de inspetores.

Abra em: https://t1zeero.github.io/Software-PA-3D/

- Configuração de junta (V, X, bloco), material, cabeçote, cunha, varredura (S-scan/E-scan), ACG/TCG e gate.
- 12 tipos de defeito editáveis e 9 situações de campo prontas.
- Telas: 3D com corte na sonda, S/E-scan, A-scan (retificado ou RF), vistas de topo, lateral e final, cobertura da solda.

Modelo de raios 2D com feixe gaussiano; amplitudes relativas ao furo de referência. Sem build: é só HTML e JavaScript (Three.js r128 via CDN).
